Facebook Page integration

User data deletion

Updated 20 October 2026

Co za dzban uses Meta authorization to connect Facebook Pages selected by an app administrator. The connection stores the Page ID and name, Page settings, and an encrypted Page access token. Facebook authorization is not used to create a Co za dzban reader account.

Disconnect and delete a Page connection

  1. Sign in to Co za dzban with an administrator account.
  2. Open Admin → Facebook Pages.
  3. Select the connected language and choose Disconnect Page.

This removes that Page's saved connection, settings, and access token from the active application database. If you cannot access the admin page, email cozadzban+privacy@bnowakowski.pl with the Page name or ID and enough information to verify that you manage it. Do not send passwords or access tokens.

Revoke access on Facebook

You can also remove the Co za dzban app from your Facebook account's Apps and Websites settings. Revoking access at Facebook stops future authorized API access, but you should also disconnect the Page in Co za dzban or request deletion of the saved connection.

What these steps do not remove

Disconnecting does not delete Co za dzban articles or Facebook posts and comments that may already exist. Manage Facebook content on Facebook. Meta controls data held by Facebook; these instructions cover data held by Co za dzban. If you need help identifying other data associated with your Page connection, use the email above.

Other data deletion requests

Anyone whose data is handled by Co za dzban may use the email above to request deletion. Describe the data or account involved so the request can be verified and handled.

See the Privacy Policy for details about data used by the Facebook Page integration.
